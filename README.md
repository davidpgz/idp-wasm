# idp-wasm

# Goal

- Expirement how far we can go with Wasm and Spinkube as computing layer for IDP
- Hypothese: Spinkube be used as a replacement for long running http server instance due to its very low cold start.

# Scope

- Local deployment
- Cloud deployment
  - Ephemeral environment
  - Production environment
- IDP features
  - NoSql data layer
  - Http server with Wasm computing
- Nodejs app
- Python/Go app
